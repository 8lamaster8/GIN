# GIN

**The model can change. GIN keeps its past.**

GIN is an autonomous cognitive system with persistent memory and a self-directed research cycle. Its knowledge and accumulated experience remain independent of any single language model.

### CURRENT SETUP

**CPU:** AMD Ryzen 5 7500F  
**GPU:** NVIDIA RTX 5070 · 12 GB VRAM  
**RAM:** 16 GB  
**LLM:** Bonsai 2 27B · ternary · ~1.76 bits per weight

**Local inference. No external LLM APIs. No search APIs. No paid subscriptions.**

### RING

A fully autonomous research and learning cycle. GIN chooses what to explore, identifies gaps in its knowledge, investigates them, and integrates the results into CORE / WORLD.

**No assigned topics. No human guidance. No predefined datasets for RING.**

### CORE / WORLD

Persistent knowledge and world model, updated through RING rather than ordinary conversations. Chat cannot directly modify them.

**What GIN learns becomes part of its future.**

### CHAT

A temporary workspace for reasoning and communication. GIN draws on its history without letting every conversation rewrite long-term knowledge.

### HANDS

GIN plans, executes, and verifies multi-step tasks using isolated tools. It writes code, works with files, builds projects, and resumes tasks from saved state after interruptions.

Tools have no direct network access.

### PRINCIPLES

**RAG retrieves. RING learns.**  
When evidence is insufficient, GIN can say **“I don't know.”**
